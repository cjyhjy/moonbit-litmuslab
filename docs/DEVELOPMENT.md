# 开发、AI 辅助与交付边界

本候选项目于 2026-10-22 开始在独立目录开发。实现由用户授权的 Codex（指定 Astra / ultra）辅助完成，包含核心编程、独立参考实现、研究、测试、演示与文档。多代理分别承担 MoonBit 核心、Python 对照、外部工具与浏览器；最终以可重复执行的证据验收。

没有把用户旧 URI Template 项目的代码或结果当成本项目语义成果。现有项目中安装的官方 MoonBit 工具链被复制到本项目隔离目录复用；`tools/bootstrap.py` 按该项目的安装器思路适配，锁定同一官方工具链档案和 SHA-256。语义核心、参考解释器和演示为本项目新增。

## 本地开发记录

- 建立目录前检查根 `PROJECTS.md`、brief 与目标路径，目标路径不存在。
- 定义有限 DSL、终态缓冲排空条件、严格预算完整性与稳定 JSON 接口。
- 实现解析、SC/TSO 状态转移、全状态去重、BFS/DFS、见证与重放。
- 首次真实运行 SB：SC 3 个结果、TSO 4 个；每个见证可重放。
- 添加 MoonBit 白盒语义回归、独立 Python 解释器、穷举短程序与外部工具对照。
- 本地浏览器与 CLI 仅调用真实 MoonBit 编译引擎；验收结果以 `reports/` 记录为准。

这些记录描述本地开发过程，不伪装成已有公开 Git 提交时间线。项目执行聊天未操作共享 Git；总控按用户授权记录了实际阶段提交，并发布了 0.1.0 基线。当前 0.2.0 改动仍在本地，发布信息与适用版本见 [PUBLICATION.md](PUBLICATION.md)。

## 0.2.0 优化记录

优化前保留 0.1.0 报告、归档与编译引擎。按动作共享未修改状态数组，用直接写入的状态键减少分配；增加共享分支不变性回归。重放新增结构化 effect，由独立 Python 解释器逐步核对。浏览器加入实验导入导出与读值来源说明，外部 herd7 对照扩展到生成程序。

审计发现旧汇总流程可能把旧浏览器通过记录与新源码哈希并列呈现；本轮改为验证产生报告时的输入快照，解包重建同时比较公共 wrapper 与 MoonBit 编译模块。性能数值来自三个固定合成负载的各五次新进程测量，不扩大为普遍提速结论。具体结果见 [OPTIMIZATION.md](OPTIMIZATION.md)。

## 实验的含义

示例、生成程序和人为构造的错误输入是合成夹具。herd7/MoonCTL 的真实运行是软件工具对照，不能称为真实硬件观测。独立参考实现仍由 AI 辅助编写，语言和状态表示不同能降低同源实现风险，不能代替外部独立审计或证明。浏览器验收验证交互与真实引擎接线，不证明所有输入的模型正确性。

研究中的版本、固定 commit、公开网页声明、实际命令和失败情况分别保存。最终测试数量、耗时、平台和未测部分以本次 machine-readable verification 为准，不以本文的过程记录替代。
